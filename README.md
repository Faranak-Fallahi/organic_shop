# 🌿 Organic Shop

A Persian RTL e-commerce platform for organic and herbal products, built with Django and Django REST Framework.

[🇮🇷 فارسی](README-fa.md)

## ✨ Features

- 🛍️ Product catalog and categories
- 🛒 Shopping cart and checkout
- 📦 Order management
- 👤 User authentication and profile management
- ❤️ Favorites
- 💬 Product comments and replies
- 📝 Blog
- 👨‍💼 Seller management panel
- 📊 User dashboard
- 🔐 REST API with JWT authentication
- 📱 Responsive Persian RTL UI

## 🛠️ Tech Stack

- Python
- Django 4.2
- Django REST Framework
- MySQL
- SimpleJWT & Djoser
- django-filter
- Bootstrap 5 RTL
- HTML, CSS, JavaScript

## 🏗️ Architecture

The project uses Django Templates for the web interface and Django REST Framework for API development.

```text
Browser
   ↓
Django Views / Templates
   ↓
Django ORM
   ↓
MySQL

API Client
   ↓
Django REST Framework
   ↓
MySQL

📌 Project Status

This project was developed as a university and portfolio project.

The payment system currently uses a Demo Payment flow and is not connected to a real payment gateway.
