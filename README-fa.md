پ# Organic Store (فروشگاه ارگانیک)

یک پلتفرم فروشگاهی جامع، مدرن و ریسپانسیو برای محصولات ارگانیک و عطاری.

## 📋 ویژگی‌های اصلی
*   مدیریت پیشرفته محصولات، دسته‌بندی‌ها و موجودی کالا
*   سبد خرید حرفه‌ای، سیستم ثبت سفارش و علاقه‌مندی‌ها
*   سیستم نظرات کاربران
*   وبلاگ اختصاصی برای تولید محتوا
*   پنل‌های مجزا برای کاربری و فروشندگان
*   طراحی ریسپانسیو با `Bootstrap 5`

## 🛠️ تکنولوژی‌های استفاده شده

**بخش بک‌اند (Backend):**
                                                                                                                              *   `Python`
                                                                                                                              *   `Django 4.2`
                                                                                                                              *   `Django REST Framework`
                                                                                                                              *   `MySQL`
                                                                                                                              *   `SimpleJWT` و `Djoser`
                                                                                                                              *   `django-filter`

**بخش فرانت‌اند (Frontend):**
                                                                                                                        *   `Django Templates`
                                                                                                                        *   `Bootstrap 5`
                                                                                                                        *   `HTML5`, `CSS3`, `JavaScript`

## 🏗️ معماری
این پروژه از ترکیب `Django Templates` (برای بخش وب) و `REST API` (برای انعطاف‌پذیری و ارتباط با کلاینت‌های دیگر) بهره می‌برد.

## ⚠️ وضعیت پروژه
پروژه فعلی یک نمونه‌کار (Portfolio) دانشگاهی است. سیستم پرداخت به صورت `Demo Payment` شبیه‌سازی شده است.
