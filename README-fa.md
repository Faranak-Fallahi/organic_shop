🌿 فروشگاه ارگانیک
🇬🇧 English
فروشگاه ارگانیک یک پلتفرم فروش اینترنتی فارسی و راست‌چین برای معرفی و فروش محصولات گیاهی، ارگانیک و عطاری است که با هدف ایجاد یک تجربه خرید ساده، منظم و قابل توسعه طراحی و پیاده‌سازی شده است.

این پروژه با Django و Django REST Framework توسعه داده شده و علاوه بر بخش فروشگاه، امکاناتی مانند مدیریت کاربران، سبد خرید، ثبت سفارش، علاقه‌مندی‌ها، نظرات، وبلاگ و پنل مدیریت فروشنده را شامل می‌شود.

✨ امکانات
🛍️ مدیریت محصولات و دسته‌بندی‌ها
🛒 سبد خرید و ثبت سفارش
📦 مدیریت سفارش و موجودی محصولات
👤 ثبت‌نام، ورود و مدیریت پروفایل کاربران
❤️ سیستم علاقه‌مندی‌ها
💬 ثبت نظر و پاسخ به نظرات
📝 سیستم وبلاگ

📱 رابط کاربری واکنش‌گرا و فارسی
